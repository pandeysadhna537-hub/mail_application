# Mail Application

A simple email-sending web application built using Node.js and Express.js.

## Features

- Send emails using the SendGrid API
- Simple REST API
- Tested using Postman
- Environment variables used for sensitive information

## Technologies Used

- Node.js
- Express.js
- SendGrid API
- Postman
- JavaScript
